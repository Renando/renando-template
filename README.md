# Renando Cinematic Portfolio (free)

Black/red film portfolio: React 19, Framer Motion, esbuild.

Use with AI: open https://renando.github.io/renando-template/template/ , copy the prompt, paste it into your coding agent, then tell it your name, photo and projects.

Manual: copy `source/` and `Asset/`, then `npm install && npm run build`.
